# 272-jenkins

A Business Central AL Extension project.

## Overview

This repository contains a Dynamics 365 Business Central AL (Application Language) extension project.

## Project Structure

- `app.json` - Extension manifest file
- `src/` - Source code directory containing AL files
- `.vscode/` - VS Code settings (gitignored)
- `.alpackages/` - AL package dependencies (gitignored)

## Getting Started

1. Install [AL Language Extension](https://marketplace.visualstudio.com/items?itemName=ms-dynamics-smb.al) for VS Code
2. Open the project in VS Code
3. Download symbols using the AL: Download Symbols command
4. Compile and publish the extension

## Requirements

- Visual Studio Code
- AL Language Extension
- Access to a Business Central environment
